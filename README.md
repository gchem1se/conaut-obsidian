# Appunti di Controlli Automatici
- Redatti in [Obsidian](https://obsidian.md/)
- sincronizzati con Git tramite il plugin [Enveloppe](https://github.com/Enveloppe/obsidian-enveloppe)
- Build automatico dai file `.md` al sito (digital-garden-like) tramite [Quartz 4](https://quartz.jzhao.xyz/)
- Il build e la pubblicazione su https://gchem1se.github.io/conaut-obsidian sono automatizzati tramite una Github Action, triggerata dallo stesso Obsidian Enveloppe al termine della sincronizzazione.
